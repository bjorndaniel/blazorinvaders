## Checked and fine
- Ranked key order: `R` + `(long)int.MaxValue - score` as 10 digits gives the same length for every `int`, invariant culture (CG32). Legacy GUIDs and `Current` sort outside `["R","S")`, and the two legacy filters plus the ranked filter cover the partition without overlap.
- `Merge` uses the ordinal `SortKey`, which gives today's stable score-descending order with ties in RowKey order. `Merge_MatchesTodaysSort` tests exactly that (stable `OrderByDescending` after `OrderBy`).
- `TakeTopAsync` with `maxPerPage: 10` stops after 10 items and stops paging, since breaking out of the loop disposes the pageable's enumerator. All queries pass the four-property `select`. The `QueryAsync<T>(filter, maxPerPage, select, ct)` and `CreateQueryFilter` calls match Azure.Data.Tables 12.9.1, and the filters stay parameterized (T7).
- `EnsureTableAsync`: a double-checked `SemaphoreSlim` around the only `CreateIfNotExistsAsync`. On failure the flag stays false, so the next call retries (AC3).
- `LegacyTopCache`: `Lazy<Task>` in a `ConcurrentDictionary` shares one load. The load runs on `CancellationToken.None` and callers use `WaitAsync(ct)`. Empty, failed and faulted results are removed only if the entry is still the same `Lazy` (P10). The back-off is instance-wide and leaves cached boards alone. A loader that throws synchronously is caught. `created!` meets CG30 (the reason is visible in the same method).
- Score mapping: a `null` score reads as 0, as today. Other non-`Int32` types are skipped and logged as a count. A missing `Name` reads as `""`.
- `Program.cs`: `TimeProvider.System` and `HighScoreStore` are registered as singletons. The response JSON shape and all status texts are unchanged.
- Docs: T3 is mitigated. The R2, TB4, T7, A4, A5 and A11 edits match the code, and each document has a Revisions or Decisions line.
